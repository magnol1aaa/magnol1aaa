## About Me
My lifelong passion for technology and tinkering has led me to develop a strong interest in both programming and cyber security. I first became interested in programming at the age of 12, when I began learning HTML and CSS to create my first web page. This early experience sparked a fascination with software development, which later evolved into an interest in game development.

At 14, I taught myself LuaU which is a programming language developed by Roblox Corporation for its game creation platform, using online tutorials and resources. Learning LuaU ignited a deep passion for programming, teaching me not only coding principles and best practices, but also the logical problem-solving skills that underpin software development.

Building on this foundation, I went on to learn additional languages such as Python and JavaScript. As my technical knowledge grew, so did my curiosity about how systems operate behind the scenes alongside what keeps them secure and how these defenses are put in place, which ultimately led to my interest in cyber security.

## Objective
My programming skills lead to me gaining an interest in cybersecurity, I now want to expand my knowledge in this field so I can apply this knowledge in my future career roles.
